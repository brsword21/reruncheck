# Why this project

## Result

Choose a small, observable **command convergence check**, not a new agent framework, generic MCP schema lockfile or record/replay proxy. Reruncheck addresses filesystem changes that successful exit codes and self-reported counters can miss. Its usefulness and adoption remain hypotheses until real maintainers use it; the repository does not claim a novel algorithm or that no equivalent exists anywhere.

### Trend estimate

**Inference, medium confidence:** attention is moving toward the quality, feedback and operational reliability of work done by agents, alongside programmable media and domain-specific workflow packages. A tiny independent verification primitive is a better fit for this launch than another general-purpose agent shell. This forecast is qualitative; the biased sample and star counts do not establish willingness to adopt or pay.

## Concrete problem evidence

A November 16 rclone issue reports an unchanged second bisync run renaming/deleting transformed names while its log ends successfully. This is a reporter's observation, not a bug independently reproduced by this project or a claim about every rclone version. It motivates a general question: what actually changed between run one and run two?[6]

The release demo is deliberately original and synthetic. It demonstrates the failure pattern without depending on rclone, patient data, a production migration, credentials or an unverified accusation against an upstream project.

## Brainstorm and counter-search

| Candidate | Decision | Reason |
|---|---|---|
| Generic MCP schema diff / lockfile | Reject | mcp-contracts and MCP Sentinel already occupy the central capability; a new CLI wrapper is not a new product.[2][3] |
| MCP migration effect checks / VCR | Reject generic variant | MCP Behavior already observes result and state changes; recorder/replay projects also exist.[4] |
| Alias-aware consumer tool-reference audit | Retain as alternative | A narrow upgrade-location/reporting gap survived source studies, but supported host syntax and identity binding are a maintenance burden. |
| Output-compaction fidelity kit | Retain conditionally | Useful only with codec-specific collision witnesses and explicit lost/unknown accounting, not another token dashboard or JSON diff. |
| Causal cassette reducer | Defer | Needs a real stable failure oracle and protocol/dependency restrictions before a responsible product can be selected. |
| Synthetic media property twin | Defer | FFmpeg/mp4-fixtures already generate media; the input-derived matching wedge brings encoder/codec/privacy costs. |
| Document-link migration preflight | Defer | Filename portability and UUID repair already exist; only a narrow supplied-map identity preflight survives. |
| Filesystem convergence receipts | Select | Observable credential-free demo, broad generator/migration/export jobs, standard-library implementation and a deliberately bounded assertion. |

These are research judgments and product hypotheses, not measured market scores. The names of alternatives are descriptions, not cleared trademarks.

## Closest prior art and intentional difference

**Molecule** already runs convergence a second time. At pinned revision `5430d28a50a91af39b761ebcb05bdc40a218eb08`, its studied Ansible-oriented idempotence step checks reported nonzero `changed=` output. That is meaningful prior art; Reruncheck instead compares its own file/path/content/type/mode/link observations and can assert the first-run expected tree. A shell script and directory diff remain sufficient alternatives for simple needs.[7]

**MCP Behavior** already checks observable filesystem/database effects for MCP tools. Reruncheck does not pretend that idea is new; its boundary is ordinary argv commands and disposable local fixture trees, with no MCP integration or model.[4]

A public batch-pipeline repeatability project already uses the working name **Twicerun**. We rejected that name after a direct repository lookup rather than claiming it was available.[8]

No upstream implementation, fixture or branding is included just because it was researched. Source studies recorded licenses and full revisions; the package is an original Apache-2.0 implementation. This statement is not a legal opinion about every dependency of every cited project.

## What would invalidate the choice

- An existing small tool already supplies equivalent command-level observed-state receipts and first-result assertions with less setup.
- The implementation merely runs a command twice and trusts its logs, or labels incomplete observation equal.
- Users need database/network idempotence rather than selected filesystem convergence.
- The demo needs a paid model, privileged account, untrusted host execution or private data to be convincing.

In those cases narrow the product honestly or contribute upstream; do not add an agent framework to justify the repository.
